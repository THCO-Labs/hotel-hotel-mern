# Homepage

The first screen a guest sees. It says what the business is, then puts a search form for city, dates and party size directly in the hero so a booking can start immediately. Below it, short value propositions explain that reserving is free and payment happens at the hotel.

Hero copy, imagery and the value propositions are project content and may change freely. The search form must keep submitting to the search route with its query parameters intact, because every downstream page reads them.
